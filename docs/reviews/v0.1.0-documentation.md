# v0.1.0 documentation review inventory

This review uses v0.1.0 as an editorial standard. It does not change release versions.
The source baseline is `a817270f13b4ef7a9b1d2895118981120546b3a2`, including merged
PR #9 (`b9900d835fcb1b7f50e7e62df044ba5b7be28151`). These commit identifiers record
the implementation used to check the documentation.

## Coverage and method

The inventory covers 821 tracked first-party files at the baseline, plus the three new
files listed below. An AST inventory extracted 7,018 comment groups from the 642 Go files
(excluding generated comment bodies). Searches identified editorial candidates; contextual
review checked their behavior, contracts and references against nearby implementation and tests.
This is an inventory and targeted contextual review, not a claim that every comment was
manually rewritten. All package documentation, 47 design decisions and 27 diagram sources
received contextual review. Script, workflow, configuration and SQL comments were also checked.

Apple's generated descriptions, third-party material, legal notices, changelogs, schema
provenance, exported-name locks and dependency versions are preserved. Project-authored
comments in eight `doc.gen.go` files were regenerated through `internal/schemagen`.
The former implementation plan is replaced by [architecture.md](../architecture.md).
Decision numbers and filenames remain stable; amendments are integrated into current decisions.

Lint ran in both modules with automatic rewriting disabled (`--fix=false`). With the
repository's `whole-files: true` setting, it reports four root-module findings and 44 server
findings on unchanged code: 4 `err113`, 7 `golines`, 3 `nilnil`, 2 `noctx`, 18 `tagliatelle`
and 14 `wrapcheck`. A check limited to changed lines passes in both modules using
`--whole-files=false --new-from-merge-base= --new-from-rev=BASE`, where `BASE` is the
baseline commit above. These results do not establish a clean unrestricted lint baseline.

The Go comparison preserves public declarations, imports, protocol values and defaults.
Generator changes affect documentation only. Configuration values and release metadata are
unchanged; a workflow step label and the Makefile's missing-generator diagnostic are editorial
changes. Script output changes are limited to the schema-update pull request template.

## Documented limitations

- Simulator and unit tests do not establish physical Apple-device interoperability.
  The declarative ACME `HardwareBound` macOS guidance remains a stated limitation.
- Scenario IDs E2E-015 and E2E-022 have no corresponding named end-to-end test. The scenario
  catalogue marks them as unimplemented; application tests cover related behavior.
- Account association reservation and confirmation span separate stores. OIDC browser handoff
  state is process-local in the reference composition. Operations and architecture guidance
  describe retry, persistence and replica requirements.
- Revocation and inbound rate limits remain optional and disabled by default. Raw check-in
  records can contain secrets outside the selected columns protected by storage sealing.

## Diagram evidence

[Artifact receipts](v0.1.0-diagrams.json) record source/output paths, SHA-256 digests, validation,
automated browser status, separate visual review status and correction rounds for every diagram.
Containment was measured at 1440×900, 1600×1000, 1920×1080 and 2048×1320. Both themes were
captured at the smallest and largest sizes. Guided views, search and focus open/close were
exercised at 2048×1320. Export controls are present; the README images are crops of the
rendered architecture SVG, with viewer controls excluded.
