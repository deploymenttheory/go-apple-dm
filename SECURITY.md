# Security policy

Do not include credentials, device identifiers or exploit details in a public issue.
Contact a maintainer listed in [CODEOWNERS](.github/CODEOWNERS) to arrange a private reporting
channel. If no private contact is available, open an issue requesting a security contact
without describing the vulnerability. GitHub private vulnerability reporting is not enabled
for this repository.

A report should include the affected commit or version, relevant configuration, reproduction
steps and expected impact. Share sensitive reproduction material only through the agreed
private channel. Deployment controls and known limitations are documented in the
[threat model](docs/security/threat-model.md) and
[enrollment security operations](docs/operations/enrollment-security.md).
